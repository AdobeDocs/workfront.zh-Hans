# Adobe Creative Cloud项目概述

您可以直接从Adobe Photoshop、Illustrator和InDesign访问Workfront项目。 在Creative Cloud应用程序窗口左侧的“项目”面板中，您可以在不离开应用程序的情况下打开、编辑和保存Workfront项目中的文档。 您还可以将新文件直接保存到Workfront项目。

只有使用Adobe云存储的项目才会与其他Creative Cloud项目一起显示在“项目”面板中。 面板会镜像Workfront中文档的文件夹结构。

在保存具有审批工作流的文档时，Workfront会创建一个新版本并保留审批历史记录。 在保存不含审批工作流的文档时，Workfront会更新最新版本。

## 先决条件

* 您的组织必须采用支持Adobe云存储的Workfront版本。
* Workfront和Photoshop、Illustrator或InDesign必须有权使用同一个Adobe Identity Management System (IMS)组织。


## 您可以从Photoshop、Illustrator或InDesign的项目面板执行哪些操作

* 直接在Photoshop、Illustrator或InDesign中打开Workfront项目文件夹和文档。 您有权访问的任何Workfront项目都会显示在“项目”面板中。
* 编辑文件并将更改保存回Workfront项目。

有关详细信息，请参阅[在Creative Cloud应用程序中使用Workfront文档](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md)。

>[!NOTE]
>
>项目面板中不支持旧版Workfront存储项目。

## 相关集成

您还可以使用Adobe Cloud Drive管理Workfront文件，并自动将更改保存到Workfront中的文档。 有关详细信息，请参阅[Adobe Cloud Drive概述](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md)。
