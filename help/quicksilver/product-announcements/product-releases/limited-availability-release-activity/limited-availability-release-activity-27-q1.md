# Adobe Workfront有限可用功能的2027年第一季度发布活动

本文介绍2027年第一季度发布的Workfront功能有限可用。

<!--keep the sentence below for all future quarterly release pages-->

有关为Adobe Workfront发布的所有有限可用性功能的列表，请参阅[Adobe Workfront有限可用性功能发布活动：文章索引](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md)。

## 有限可用性功能的发行说明

此部分包含新功能的发行说明。

### 能够展开或折叠所有组

>[!NOTE]
>
>生产发布日期： 2026年10月27日

现在，您可以使用第一列顶部的箭头图标来展开或折叠增强列表中的所有分组。 这包括按时间分段的报表。

以前，您只能展开或折叠分组设置中的所有组。

有关增强列表的详细信息，请参阅[使用增强列表](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md)。

### 查看对时间分段报表的选择

>[!NOTE]
>
>生产发布日期： 2026年10月27日

在时间分段报表中创建新视图的体验已经过简化，因此，如果只有一个视图类型可用，则无需再选择视图类型。

### 在时相报表上固定合计列

>[!NOTE]
>
>生产发布日期： 2026年10月27日

您现在可以固定&#x200B;**总计**&#x200B;列，使其在时间分段报表的右侧保持可见。

此功能也可在使用矩阵视图的其他屏幕上使用，如人员配备计划。
