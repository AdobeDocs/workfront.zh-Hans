# 2027年第一季度管理员增强功能

本页介绍了管理员在2027年第一季度发布中对“预览”环境所做的增强。 如上所述，这些增强功能将在“生产”环境中提供。

有关2027年第一季度发布周期中此时可用的所有更改列表，请参阅[ 2027年第一季度发布概述](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md)。

## 可用于Workfront Planning的环境升级

>[!NOTE]
>
>生产和沙盒快速发布： 2026年11月12日
>适用于每个人的生产、预览、沙盒： 2026年12月17日
>[!BADGE 超出计划]{type=Neutral}

>[!NOTE]
>
>Workfront Planning的环境促销活动仅适用于除工作流包外还购买了Workfront Planning包的客户。 已购买Workfront Planning作为独立产品的客户无法使用此功能。

Workfront管理员现在可以将Workfront Planning工作区及其对象从一个环境提升到另一个环境，因此您不再需要手动重建配置。 这样可节省时间并减少手动设置带来的错误。

不属于导出工作区的记录、自动化和字段无法提升。

此功能需要Prime或Ultimate Workflow和Planning包、标准许可证以及Workfront管理员访问权限。

有关信息，请参阅[为Workfront Planning使用环境升级](/help/quicksilver/planning/general/planning-environment-promotion.md)。

## 删除附加自定义表单的权限

>[!NOTE]
>
>预览： 2026年10月29日
>生产快速发布： 2026年11月12日
>适用于所有人的生产： 2027年1月21日

共享自定义表单时，您现在可以为具有表单管理访问权限的用户设置权限，以从表单附加到的对象中删除表单。

有关详细信息，请参阅[共享自定义表单](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/share-access-to-a-custom-form.md)。

## 将自定义字段标记为收藏

>[!NOTE]
>
>预览： 2026年10月29日
>生产快速发布： 2026年12月17日
>适用于所有人的生产： 2027年1月21日

现在，您可以在字段列表或自定义表单设计器中将自定义字段标记为收藏。 当您使用某些列表和报告（例如项目、任务和问题列表）并构建过滤器、视图和分组时，收藏字段显示在建议部分中可用字段列表的顶部。

标记为收藏夹的字段也会显示在表单设计器中的字段库顶部。

有关详细信息，请参阅[创建自定义表单](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/form-designer/design-a-form/design-a-form.md)。

## 更改格式时在自定义字段上验证的值

>[!NOTE]
>
>预览： 2026年10月29日
>生产快速发布： 2026年11月12日
>适用于所有人的生产： 2027年1月21日

现在，当您将现有文本自定义字段格式更改为数字或货币时，系统会检查是否存在不兼容的值。

如果该字段的现有值全部为数字，则系统只是更新字段格式。 但是，如果任何现有值为非数字，系统会显示一条警告消息，指出保存字段时将清除不兼容的值。

有关详细信息，请参阅[创建自定义表单](/help/quicksilver/administration-and-setup/customize-workfront/create-manage-custom-forms/form-designer/design-a-form/design-a-form.md)。

## 更改历史记录现在跟踪画布功能板对象

>[!NOTE]
>
>预览： 2026年10月29日
>生产快速发布： 2026年10月29日
>为每个人生产：2026年10月29日
>[!BADGE 超出计划]{type=Neutral}

更改历史记录现在会记录对画布功能板的更改。 您可以查看是谁创建、更新或删除了功能板或报表，以及何时创建、更新或删除了功能板或报表以及更改了哪些内容。

要开始跟踪画布仪表板更改，必须在设置>更改跟踪>配置中配置&#x200B;**仪表板**、**报表**&#x200B;和&#x200B;**报表配置**&#x200B;对象。

有关详细信息，请参阅[查看和管理更改历史记录](/help/quicksilver/administration-and-setup/add-users/create-and-manage-users/view-and-manage-change-history.md)。
