# Adobe Workfront Planning发布活动的构思空间

<span class="preview">此页面上的信息引用了尚未公开的功能。 它只能作为&#x200B;**构思空间Beta**&#x200B;程序的一部分提供。</span>

<span class="preview">有关详细信息，请参阅[Adobe Workfront计划的构思空间入门](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md)。</span>

本文介绍了在&#x200B;**构思空间Beta**&#x200B;期间为Workfront Planning的构思空间发布的功能。 创意空间开放Beta计划于2026年11月12日至2027年2月1日之间运行。

对于Adobe Workfront Planning版本，请参阅[Adobe Workfront Planning版本活动：文章索引](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md)。

## Adobe Workfront Planning中构思空间的新主页区域

>[!NOTE]
>
>可供构思空间测试版客户预览和生产环境使用： 2026年11月25日

当您从Workfront华夫饼菜单访问创意空间时，现在可打开创意空间主页区域。 从此处，您可以重新打开现有画布或创建现有画布，这样您就不再需要只是从空白画布开始访问现有画布。 主页区域将您最近的画布显示为拼贴，在屏幕下方列出了所有其他画布，并包括一个搜索框。 在画布内工作时，使用新的“主页”按钮返回创意空间主页区域。

有关信息，请参阅[在构思空间](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md)中创建简述。
